# 华东师范大学化学与分子工程学院奖学金评选系统

## 项目概述

本项目为华东师范大学化学与分子工程学院开发的本科生奖学金评选系统，采用 Soft UI 设计风格，提供美观、易用的界面。

## 文件结构

```
pages/scholarship/          # 微信小程序文件
├── scholarship.wxml        # 页面结构
├── scholarship.wxss        # 页面样式
├── scholarship.js          # 页面逻辑
└── scholarship.json        # 页面配置

preview/                    # 预览文件
└── scholarship-main-preview.html  # HTML预览版本
```

## 功能模块

### 1. 学生信息模块
- 姓名输入
- 年级输入
- 学号输入
- 综合评定成绩实时显示

### 2. 学业成绩模块
- 学分数输入
- 平均绩点(GPA)输入
- 自动计算：学业成绩 = GPA × 20

### 3. 学生工作加分模块
- 职务下拉选择：
  - 无 (0分)
  - 学生会主席团成员 (1.0分)
  - 学生会部长/主要班委/社团社长/党支部支委 (0.8分)
  - 学生会副部长/社团副社长 (0.6分)
  - 其他班委/其他学生干部 (0.5分)
  - 参与志愿服务-待审核认定 (0.1-1.0分)
- 证明材料上传功能
- **注意**：多个职务只取最高项，不累加

### 4. 素质类加分模块

#### 4.1 学科竞赛/创新创业
| 级别 | 一等 | 二等 | 三等 | 四等 |
|------|------|------|------|------|
| 国家级 | 5 | 4 | 3 | 2 |
| 省市级 | 4 | 3 | 2 | 1 |
| 校级 | 1.5 | 1 | 0.5 | - |

#### 4.2 文体比赛
| 级别 | 一等 | 二等 | 三等 | 集体奖 |
|------|------|------|------|--------|
| 国家级 | 3 | 2 | 1 | 0.3 |
| 省市级 | 2 | 1 | 0.5 | 0.2 |
| 校级 | 1 | 0.5 | 0.3 | 0.1 |

#### 4.3 荣誉称号
- 国家级：5分
- 省市级：3分
- 校级：1分
- 院级：0.5分

#### 4.4 书院/学院活动
- 第二课堂活动：一等奖(0.3)/二等奖(0.2)/三等奖(0.1)
- 优秀志愿者：0.1分

#### 4.5 学术成果
- SCI研究性论文/发明专利：第一作者(3)/第二作者(1.5)
- SCI综述性论文：第一作者(2)/第二作者(1)
- 其他学术论文：第一作者(1)

#### 4.6 科创项目
| 项目类型 | 负责人 | 组员 |
|----------|--------|------|
| 国家级项目结项 | 1 | 0.8 |
| 上海市项目结项 | 0.8 | 0.6 |
| 校级项目/大夏科研基金 | 0.6 | 0.4 |
| 师范生教育研习 | 0.4 | 0.2 |

#### 4.7 其他
- 义务献血：0.3分

### 5. 底部操作区
- 综合评定成绩总分实时显示
- 保存草稿按钮
- 提交申请按钮

## 设计规范

### 视觉设计
- **设计风格**：Soft UI（柔和阴影 + 圆角卡片）
- **主题色**：#1E5AA8（学院蓝）
- **渐变色**：#667EEA（渐变紫蓝）
- **背景色**：#F8FAFC（浅灰白）
- **图标风格**：统一的表情符号图标

### 布局设计
- 卡片式布局，每个模块独立卡片
- 8px 栅格系统统一间距
- 清晰的视觉层次和分组
- 375px 移动端优化宽度

### 交互设计
- 下拉选择器使用原生 picker/select 组件
- "+ 添加"按钮添加新项目
- "删除"按钮移除已添加项目
- 实时计算并显示所有分数
- 表单验证和错误提示

## 使用说明

### 微信小程序版本
1. 将 `pages/scholarship/` 目录复制到微信小程序项目中
2. 在 `app.json` 中添加页面路由：
```json
{
  "pages": [
    "pages/scholarship/scholarship"
  ]
}
```
3. 编译运行即可

### HTML预览版本
1. 在浏览器中直接打开 `preview/scholarship-main-preview.html`
2. 或使用本地服务器：
```bash
cd preview
python -m http.server 8080
# 访问 http://localhost:8080/scholarship-main-preview.html
```

## 计算逻辑

综合评定成绩 = 学业成绩 + 学生工作加分 + 素质类加分总计

其中：
- **学业成绩** = 平均绩点(GPA) × 20
- **学生工作加分** = 所选职务对应分值（仅取最高项）
- **素质类加分总计** = 所有添加项目分值之和
